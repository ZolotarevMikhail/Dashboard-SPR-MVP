# Как пользоваться дашбордом «Анализ продаж на Wildberries»

Дашборд показывает продажи, прибыль, рекламу, остатки и структуру по типам товаров на Wildberries.
Цель — за минуту увидеть, что заказали и сколько реально заработал, без сводки по разным вкладкам.

Файл `index.html` — единственный. Внешних библиотек нет, всё работает прямо в браузере.
Сделан в стиле сайта sproots.ru (чёрный/серый/белый + жёлтый акцент).

---

## 1. Быстрый старт — демо-режим

1. Дважды кликни по файлу `index.html`. Он откроется в браузере.
2. Сразу увидишь графики и цифры — это **демо-данные** (спортивные товары, придуманные продажи). Сверху бейдж «демо-данные».
3. Можно переключать периоды, фильтровать по типам, нажимать кнопки — всё работает.

Демо-режим не требует интернета и токена.

---

## 2. Подключить свои настоящие данные WB

### Шаг 1. Получить API-токен Wildberries
1. Зайди в кабинет продавца WB → **Профиль** → **Настройки** → **Доступ к API**.
2. Создай и скопируй токен (длинная строка `eyJhbGciOi...`).
3. Токен даёт доступ к твоим данным. Не показывай его никому.

### Шаг 2. Открыть дашборд через локальный сервер
Двойной клик по `index.html` подходит **только для демо**. Для загрузки реальных данных браузер требует, чтобы файл открывался через сервер.

Запуск локального сервера (одна команда в терминале):

```
cd путь/до/папки/с/дашбордом
python3 -m http.server 8765
```

Затем открой в браузере: **http://localhost:8765/index.html**

Сервер работает, пока открыто окно терминала. Закрыл терминал — сервер остановился. Данные уже загружены в дашборд, перезагружать не нужно.

### Шаг 3. Вставить токен и задать пароль
Токен хранится **зашифрованным** — посмотреть его можно только после ввода пароля, который ты задаёшь сам.

1. Нажми кнопку **⚙ Настройки** (справа вверху).
2. На вкладке **«Подключение»**:
   - В поле **«API-токен»** вставь токен из кабинета WB.
   - В поле **«Пароль доступа»** придумай пароль (он нужен для разблокировки токена).
   - Нажми **Сохранить**. Токен зашифруется паролем и сохранится в браузере.
3. Кнопка **⟳ Обновить** (жёлтая, вверху) станет активной.

Пароль **не хранится нигде**. Если забудешь — придётся заново вставить токен. Вводить пароль нужно один раз за открытие дашборда (после перезагрузки страницы — снова).

### Шаг 4. Загрузить данные
Нажми **⟳ Обновить**. Дашборд подтянет данные из кабинета WB: продажи, заказы, остатки, рекламу, товары. Бейдж сменится на «данные из API».

Данные кешируются в браузере — после перезагрузки страницы они на месте. Но чтобы загрузить **свежие** данные после перезагрузки, нужно снова разблокировать токен паролем (Настройки → «Разблокировать токен»).

### Блокировка токена
- **🔒 Заблокировать** (в Настройках) — убирает открытый токен из памяти. Кнопка «Обновить» гаснет, пока не разблокируешь.
- **🔓 Разблокировать токен** — вводишь пароль, токен расшифровывается на текущую сессию.
- **👁** (глаз рядом с полем токена) — показать/скрыть токен. Работает только если токен разблокирован.

## 3. Что видно на дашборде

### KPI-плитки (верхний ряд)
- **Выручка** — за период (с учётом возвратов).
- **Заказы** — количество заказов.
- **Прибыль** = выручка − комиссия WB − реклама − себестоимость.
- **ROI рекламы** — во сколько раз реклама окупается. Меньше 1× — реклама в минус.
- **Остатки** — суммарно по всем складам WB.
- **Возвраты** — штуки и доля от заказов.

### Выводы
Автоматическая выжимка по периоду: прибыль, динамика к прошлому периоду, окупаемость рекламы, лучший и убыточные товары, возвраты, заканчивающиеся остатки.

### Графики
- **Структура продаж по типам** — круговой график: доли выручки по группам товаров.
- **Динамика** — выручка / заказы / прибыль по периоду. Метрика переключается кнопками над графиком.
- **Реклама** — расходы на продвижение по периодам.
- **Прибыль по товарам** — рейтинг товаров: кто зарабатывает (зелёные), кто тянет вниз (красные).
- **Остатки по товарам** — что заканчивается (красным — меньше 20 шт).

### Таблица «Товары»
По каждому товару: артикул, название, продано шт., выручка, комиссия WB, реклама, себестоимость за шт. и всего, прибыль, ROI, остатки.

## 4. Фильтры периода и типов

### Период (выпадающий список)
- **День / Неделя / Месяц / С начала года** — быстрые периоды относительно даты в поле «Дата».
- **Произвольный диапазон** — появляются два поля «от» и «до», задаёшь любые даты. Дата «до» включительно.

### Тип товаров (выпадающий список)
- **Все типы** — показываются все товары.
- Конкретный тип (например, «Силовые») — графики, KPI и таблица пересчитываются только по товарам этого типа.

Типы товаров задаются в Настройках (см. раздел 5).

---

## 5. Себестоимость и типы товаров (вкладка «Товары»)

WB не отдаёт себестоимость и не знает твои группы товаров — их задаёшь ты.

1. **⚙ Настройки** → вкладка **«Товары»**.
2. Таблица: по каждому товару — артикул, название, **тип** (выпадающий список) и **себестоимость за штуку** (поле ввода).
3. Меняй значение — оно сохраняется в браузере и сразу пересчитывает прибыль во всех плитах и графиках.
4. **Очистить себестоимости** — сбросить все введённые значения.
5. **＋ Новый тип** — добавить свой вариант типа в выпадающие списки.
6. **⤓ Загрузить CSV…** — массовый импорт себестоимости из файла (см. раздел 5а ниже).
7. **⤓ Скачать текущие себестоимости** — выгрузка в CSV для редактирования в Excel и обратной загрузки.

Для демо-товаров типы заданы заранее. **При подключении к WB список товаров поменяется** — задай себестоимость и типы под свои реальные товары. Значения хранятся по артикулу продавца.

### 5а. Массовый импорт себестоимости (для большого каталога)

Если у тебя десятки или сотни SKU, вбивать себестоимость в таблицу по одной — долго. Используй CSV.

**Шаг 1. Скачай шаблон.**
В Настройках → «Товары» внизу есть ссылка **[cost-template.csv]** — сохрани файл.

**Шаг 2. Заполни в Excel или Google Sheets.**
Открой шаблон, заполни колонки:

| Колонка | Что писать | Обязательна? |
|---|---|---|
| `vendorCode` | твой артикул WB (как в кабинете продавца) | можно одну из четырёх |
| `nmId` | числовой ID карточки WB (видно в адресной строке карточки) | можно одну из четырёх |
| `barcode` | штрих-код EAN-13 (одинаковый в WB и в твоей 1С/Excel) | можно одну из четырёх |
| `cost` | себестоимость за штуку, ₽ | **обязательна** |

Достаточно **любой одной** из колонок-ключей (vendorCode / nmId / barcode). Дашборд сначала ищет по `barcode`, потом по `nmId`, потом по `vendorCode`. Лишние колонки можно удалить.

**Шаг 3. Сохрани как CSV.**
В Excel: *Файл → Сохранить как → Тип файла: CSV (разделители — запятые)*. В Google Sheets: *Файл → Скачать → CSV*.

**Шаг 4. Загрузи в дашборд.**
В Настройках → «Товары» нажми **⤓ Загрузить CSV…** и выбери файл. Появится отчёт:
- сколько строк сопоставлено,
- сколько не найдено (с указанием строки и причины),
- подсказка, если не сопоставлено: проверь, что товар есть в дашборде, обнови данные из WB (⟳), если добавлял новые.

Повторно загружать можно сколько угодно раз — старые себестоимости обновляются, новые добавляются.

## 6. Экспорт в Excel/CSV

Кнопка **⬇ Экспорт CSV** выгружает текущий видимый срез (с учётом фильтров) в файл `.csv`. Открывается в Excel или Google Sheets.

Импорт своего CSV — кнопка **⤓ CSV** (вверху) или в Настройках → «Данные» → «Выбрать CSV-файл».
Формат: колонки `date, article, qty, revenue, commission, returns, ad_spend, stock`.

## 7. Как обновляются данные (инкрементальный режим)

Дашборд **не скачивает всё заново** при каждом нажатии «Обновить». Он запоминает, до какой даты уже докачал, и каждый раз тянет только новые дни. Поэтому:

- **Первая загрузка** — с даты, которую ты задаёшь (по умолчанию 1 января текущего года). Может занять несколько минут.
- **Каждое следующее обновление** — несколько секунд: подтянутся только новые дни от последней даты в кэше до сегодня.
- **Где посмотреть состояние кэша**: Настройки → «Данные» → «Начальная дата загрузки» → подсказка внизу покажет, сколько дней в кэше продаж/заказов/рекламы.
- **Если хочешь перекачать с другой даты** — измени «Начальную дату» и нажми «Сохранить дату», потом «Очистить кэш» → следующее обновление пойдёт с новой даты.
- **Если нужно полностью сбросить** — кнопка «Очистить кэш» в Настройках. Сотрёт локальный кэш, токен останется.
- **Реклама: первая загрузка с 1 января** может занять **~9 минут** (много кампаний × окна по 30 дней × паузы WB 22 сек между запросами). После неё обновления — секунды. Если WB временно отвечает «слишком много запросов» — обновление само пропустит проблемный кусок и попробует в следующий раз.

## 8. Тема

Кнопка **🌙 / ☀** справа вверху — переключение тёмной/светлой темы. Запоминается.
Все настройки (токен, себестоимость, типы, тема) хранятся только в этом браузере на этом компьютере.

## Если что-то не работает

- **Кнопка «Обновить» серая** — токен заблокирован или не задан. Открой Настройки → «Подключение», вставь токен + пароль или разблокируй существующий.
- **«Неверный пароль» при разблокировке** — пароль не подходит. Если забыл — вставь токен заново и задай новый пароль.
- **«Не удалось получить список товаров»** — токен неверный или нет прав на раздел «контент». Перевыпусти токен в кабинете WB с полным доступом.
- **Данные не грузятся, но токен есть** — возможно, открыт файл двойным кликом (file://). Открой через локальный сервер (раздел 2, шаг 2).
- **Цифры странные / нули** — проверь период, диапазон дат и фильтр по типу.
