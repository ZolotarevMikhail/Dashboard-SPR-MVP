      Настройки

      Чтобы дашборд тянул данные из кабинета Wildberries, нужен API-токен. Токен хранится зашифрованным — посмотреть его можно только после ввода пароля, который ты задаёшь сам.

      Пароль доступа

      Пароль не хранится нигде. Если забудешь — придётся заново ввести токен. Вводить пароль нужно один раз за открытие дашборда.

      API-токен Wildberries

      Где взять: кабинет WB → Профиль → Настройки → Доступ к API → создай и скопируй токен.

      ⚠ Токен даёт доступ к кабинету. Не передавай его никому. Если кто-то узнал пароль или токен — перевыпусти токен в кабинете WB.

      Здесь задаются себестоимость (WB её не отдаёт) и тип товара для группировки. Значения сохраняются в браузере по артикулу.

      Себестоимость и типы товаров

      АртикулНазваниеТипСебест./шт, ₽

      Массовый импорт себестоимости

      Для большого количества товаров удобнее загрузить CSV-файл (Файл → Сохранить как → CSV в Excel). Шаблон с примером: cost-template.csv.

      Колонки (любой порядок, лишние игнорируются): vendorCode (артикул WB), nmId (числовой ID карточки), barcode (EAN-13), cost (себестоимость за шт., ₽).

      Сопоставление: сначала по barcode, затем по nmId, затем по vendorCode. Если ключ не найден — строка попадёт в отчёт «Не сопоставлено».

      Для демо-товаров типы заданы заранее. При подключении к WB список товаров поменяется — задай типы под свои товары. «Новый тип» добавляет вариант в выпадающие списки.

      Источник данных

      Без токена дашборд работает на CSV или демо-данных. CSV нужен со столбцами: date,article,qty,revenue,commission,returns,ad_spend,stock.

      Начальная дата загрузки

      Продажи, заказы и реклама подгружаются инкрементально: первая загрузка — от этой даты, дальше — только новые дни (от последней даты в кэше). Так обновление занимает секунды, а не минуты. Если очистить кэш (кнопка ниже) — снова начнёт качать с этой даты.
