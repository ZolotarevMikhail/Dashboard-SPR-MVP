# Спецификация — Dashboard SPR MVP

**Что это:** MVP-версия дашборда продаж для селлеров Wildberries. Все данные внутри файла как демо — фиктивные цифры для согласования интерфейса и логики.

**Цель MVP:** показать заказчику, как выглядит и работает готовый дашборд, до подключения реальных данных.

## Экраны и блоки

### KPI-плитки (6 штук сверху)
- Выручка
- Заказы
- Средний чек
- Возвраты
- Реклама
- Прибыль

### Графики
- **Динамика продаж** — выручка и заказы по дням
- **Реклама** — расходы и CTR по дням
- **Прибыль по товарам** — рейтинг (кто зарабатывает, кто тянет вниз)
- **Остатки** — топ товаров с минимальным запасом

### Таблица товаров
Артикул, название, продано (шт.), выручка, реклама, себестоимость, прибыль, ROI, остатки.

### Управление
- Переключатель периода: год / месяц / неделя / день + выбор дат
- Фильтры по типу товара
- Переключатель темы: светлая / тёмная
- Экспорт текущего среза в CSV

## Темы и стили

- Светлая и тёмная темы — переключатель в правом верхнем углу
- Палитра sproots: `#f9f9f9` / `#151515` / `#fbcf02`, Montserrat, радиус 4px

## Технические требования

- Один HTML-файл, без внешних библиотек и CDN — всё inline
- SVG-графики на чистом JS, без Chart.js / D3
- Адаптивный: телефон + компьютер (от 400px до 1920px)
- Демо-данные встроены в файл — дашборд сразу показывает графики и KPI без настройки

## Что не входит в MVP

- Подключение к API Wildberries (это в полной версии)
- Хранение токенов
- Реальные данные клиента
- Автообновление по таймеру

Полная версия с подключением к API WB будет собрана отдельно после согласования MVP с заказчиком.
