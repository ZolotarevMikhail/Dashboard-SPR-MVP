# Дашборд продаж Wildberries — спецификация (ТЗ)

**Заказчик:** Михаил (спортивные товары; основная площадка — Wildberries).
**Режим доставки:** Режим 2 — Лайв-браузер на компьютере заказчика, данные по API WB.
**Цель:** каждое утро за минуту видеть, что заказали и сколько реально заработал на WB.

## Боли заказчика
- Не видит реальную прибыль после комиссий и расходов WB.
- Не понимает, какие товары зарабатывают, а какие тянут вниз.
- Реклама жжёт бюджет, отдача не ясна.
- Нет времени сводить цифры по разным вкладкам вручную.

## Источник данных — API Wildberries
| Метрика | Метод WB | Автоматически |
|---|---|---|
| Продажи и возвраты | `/api/v1/supplier/sales` | да |
| Заказы | `/api/v1/supplier/orders` | да |
| Остатки (срез) | `/api/v1/supplier/stocks` | да |
| Комиссии и удержания | `/api/v5/supplier/reportDetailByPeriod` | да |
| Расходы на рекламу | `/adv/v2/fullstats` | да |
| Товары (название, артикул) | `/content/v2/get/cards/list` | да |
| Себестоимость | ввод заказчика в дашборде | нет (localStorage) |

## Расчёт прибыли
**Прибыль = выручка − комиссия WB − расходы на рекламу − себестоимость.**
Возвраты вычитаются из выручки автоматически + показываются отдельной плиткой.
**ROI рекламы** = выручка с периода / расходы на рекламу (во сколько раз окупается).

## Что показываем
### KPI-плитки
- Выручка (чистая, с учётом возвратов)
- Заказы (шт.)
- Прибыль
- ROI рекламы
- Остатки (шт., сумма по всем складам WB)
- Возвраты (шт. и сумма)

### Графики
- Выручка и заказы по периоду (день/неделя/месяц)
- Прибыль по товарам — рейтинг (кто зарабатывает, кто тянет вниз)
- Расходы на рекламу и отдача по периоду
- Остатки по товарам (что заканчивается)

### Таблица товаров
Артикул, название, продано шт., выручка, комиссия, реклама, себестоимость, прибыль, ROI, остатки.

### Управление
- Переключатель периода: год / месяц / неделя / день + выбор дат. По умолчанию — с начала года.
- **Одна кнопка «Обновить»** — тянет свежие данные из API по требованию. Без таймера и автозапуска.
- Панель «Настройки» — вставка WB-токена (хранится в localStorage браузера, только у заказчика).
- Ввод себестоимости по артикулу продавца (хранится в localStorage).
- Экспорт текущего среза в CSV.

## Требования к сборке
- Один HTML-файл, без внешних библиотек и CDN — всё inline (правило dashboards-offline-no-cdn).
- Графики — чистый SVG/JS; оформление по скиллу dataviz (палитра, свет/тьма).
- Адаптив: телефон + компьютер.
- Демо-данные внутри файла — дашборд сразу показывает графики и KPI без настройки.
- Ключи только в localStorage, никогда в HTML/коде.
- Режим 2: для Ozon «из файла» не работает — WB работает и из файла, и на localhost/хостинге.
